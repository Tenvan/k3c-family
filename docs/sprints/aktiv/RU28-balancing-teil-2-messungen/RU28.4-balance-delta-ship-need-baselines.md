**Vorentscheidungen:**
- `baselineName` (`regexp ^[A-Za-z0-9_-]{1,40}$`) wird eine Prüf-Funktion mit Zeichenklassen.
- `time.Now().Format(time.RFC3339)` (`Saved`): Rust-std kennt keine Zeitzone; geschrieben wird UTC im RFC-3339-Format (`2026-11-17T10:00:00Z`, eigene kleine Umrechnung aus `SystemTime`). Abweichung zu Go (Ortszeit mit Versatz) im Ergebnis nennen; Tests vergleichen `Saved` nicht wörtlich (wie Go). Eine Zeit-Crate wäre eine Freigabe von 🧑.
- Dateien schreiben und lesen mit `std::fs` (kein Sim-Schritt, Leitfaden § 5 betrifft die Sim); Tests schreiben unter `std::env::temp_dir()`.
- `sync/atomic` in `baselines_test.go` → `std::sync::atomic`.

## Schritte

1. `git merge origin/main`. Orakel mit der Go-Fassung festhalten (`.work/orakel/`): `task rust:game:build` grün, dann `cp dist/k3c-game/LIZENZEN.txt .work/orakel/LIZENZEN.go.txt`; `task rust:game:dist:check > .work/orakel/pruefen.go.txt 2>&1` (Exit-Code notieren); Zeitstempel und Größen von `public/audio/atlas.*` notieren.
2. `tools/sync` portieren, Test aus `main_test.go`.
3. `tools/rustpaket` portieren (`lizenzen.ts`, `pruefen.ts`, `main.ts`); `pruefen` bekommt eine Dateiliste als Eingabe statt eines `fs.FS`, damit die Tests ohne Platte laufen; Tests aus `lizenzen_test.go`, `pruefen_test.go` mit `testdata/`.
4. `tools/ruletable` portieren (`table.ts` aus `table/table.go`, `main.ts`); Tests aus `table_test.go`, `main_test.go`.
5. `tools/soundatlas` portieren (`atlas.ts`, `main.ts`, ffmpeg-Aufrufe mit denselben Argumenten); Test aus `atlas_test.go`.
6. `tsconfig.json` › `include` um die vier Ordner erweitern.
7. Tasks umstellen: `rust/Taskfile.yml` › `game:dist` (`bun tools/sync/main.ts $args`, `bun tools/rustpaket/main.ts lizenzen …`, `bun tools/rustpaket/main.ts pruefen -lokal …`, `CGO_ENABLED` raus), `game:dist:check`; `tools/Taskfile.yml` › `rules` (`bun tools/ruletable/main.ts`), `soundatlas` (`bun tools/soundatlas/main.ts`, `sources` auf `tools/soundatlas/*.ts`, Vorbedingung Go raus, ffmpeg bleibt), `portcheck` entfernen. Keine EXE mehr nach `bin/`.
8. CI: im Job `rust` den Schritt `actions/setup-go` und den Go-Hinweis im Kommentar entfernen; in `release.yml` `actions/setup-go` entfernen (bun dort einrichten, falls es fehlt: `oven-sh/setup-bun@v2`, `bun-version: 1.4.2`, und `bun install --frozen-lockfile`, wie im Job `rust`).
9. Orakel-Vergleich: `task rust:game:build`; `cmp dist/k3c-game/LIZENZEN.txt .work/orakel/LIZENZEN.go.txt` (byte-gleich); `task rust:game:dist:check` mit gleichem Exit-Code und gleichen Meldungen; `task gen:rules` und `git diff --exit-code docs/rules/materialien-gebaeude.md`; `task gen:soundatlas -f` und `git diff --stat public/audio/` – `atlas.json` byte-gleich; weichen die Audio-Dateien nur durch ffmpeg-Metadaten ab, die eingecheckten Dateien per `git checkout -- public/audio/atlas.ogg public/audio/atlas.mp3` behalten und im Ergebnis melden.
10. Codemaps der vier Ordner auf die TS-Fassung umschreiben (Go-Dateien liegen bis RU71.4).
11. Gezielt `bunx vitest run tools/sync tools/rustpaket tools/ruletable tools/soundatlas`, `task lint`, `task typecheck`; dann `task check:diff`. `.work/orakel/` löschen. Ergebnis, Status `fertig`, ein Commit, Push.

## Kontext

- Betroffene Dateien: `docs/rules/ist-abgleich.md`, `ist-gegner-bosse.md`, `ist-material-gebaeude.md`, `ist-monarch-buerger.md`. Sie werden von `docs/rules/*.md` (`bosse.md`, `buerger.md`, `gegner.md`, `materialien-gebaeude.md`, `monarch.md`, `stufen.md`, `wirtschaft.md`) und von Tickets in `docs/backlog/` (u. a. B-099, B-112, B-116, B-118, B-119, B-121, B-122, B-128 bis B-131) verlinkt; Dateien in `docs/sprints/erledigt/` und `docs/backlog/archiv/` bleiben unverändert (Historie).
- Verschieben mit `git mv`, damit die Historie bleibt. Relative Links in den archivierten Dateien selbst (`stufen.md` usw.) auf `../` anpassen, falls nötig.
- `CLAUDE.md`, Zeile „Spielstruktur (003)“: heute „Umsetzung offen, Ist-Code: eine Stufe = eine Welt, `docs/rules/stufen.md`“. Seit SP12 bis SP14 gibt es Inseln und Stufen im Go-Code (`engine/sim/island*.go`, Raum auf Insel, Protokoll v3). Der neue Satz nennt nur, was im Code belegt ist; was offen bleibt (z. B. mehrere Inseln, Inselwechsel, B-103), steht als „noch offen“ mit Ticket.
- `tests/planning.test.ts` prüft nur Tickets und Sprints; Links in Regeldateien prüft nichts, deshalb Suche per `grep` (Schritt 3).

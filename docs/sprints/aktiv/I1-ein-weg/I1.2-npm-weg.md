## Ziel

Außerhalb von k3c-dev ruft nichts mehr `npm run`; `package.json` hat keine Skripte, die Workflows rufen `task`.

## Kontext

- `Taskfile.yml` hat die Tasks (`install`, `dev`, `lint`, `typecheck`, `test`, `check`, `build`, `serve`, `start`, `check:go`, `check:dev`, `k3c-dev`, `k3c-dev:build` …); sie rufen `npx` direkt, nicht `npm run`.
- Fundstellen (Stand `grep -rn "npm run"`): `package.json` (Skripte), `.github/workflows/ci.yml`, `deploy-pages.yml`, `release.yml`, `.github/pull_request_template.md`, `Dockerfile` (falls), `README.md`, `requirements.md`, `docs/arbeitsweise.md`, `docs/vorlagen/session.md`, `docs/decisions/001-server-engine-go.md`, Fehlermeldung in `cmd/k3c-server/main.go` und `main_test.go` („Erst bauen: npm run build“ → `task build`), Meldungen in `server/` falls noch vorhanden.
  k3c-dev (Prüfkatalog, Mock im Frontend) gehört zu I1.3.
- CI: `go-task/setup-task` (Version in `requirements.md` bzw. `Taskfile.yml` abstimmen) vor dem ersten `task`-Aufruf in jedem Job; Jobs behalten ihre Schritte, nur die Befehle werden `task <name>`.
- Entscheidungen (`docs/decisions/`) werden nicht umgeschrieben, nur dieser eine Befehlstext aktualisiert, wenn er noch als Anleitung gilt (ein Satz Anmerkung).

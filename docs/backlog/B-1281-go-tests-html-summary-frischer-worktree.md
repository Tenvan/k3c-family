## Ausgangslage

RU31.3/RU31.4: Der Go-Test `TestRustRefSummary` ist unter Windows rot (vermutlich CRLF durch autocrlf, nicht geprüft). `TestHTMLEigenstaendig` und `TestHTMLOhneGrafiken` sind in frischen Worktrees rot, weil die Papierschnitt-Grafik fehlt (nicht eingecheckt, B-737); die Rust-Variante prüft die Grafik-Schlüssel nur, wenn `public/grafik/…` existiert.

## Ziel

Die drei Go-Tests laufen auch ohne `gen:paper` bzw. unter Windows grün: CRLF normalisieren wie `TestRustRefInsights`, Grafik-Prüfung nur wenn vorhanden.

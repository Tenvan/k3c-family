- **Regeln (B-213):** Zeile `^\d+\. ` am Zeilenanfang = Punkt einer geordneten Liste (`ol`), aufeinanderfolgende Punkte bilden eine Liste; `[ ] ` bzw. `[x] ` am Anfang eines Listenpunkts → ☐ bzw. ☑; im Fließtext bleiben `[ ]`/`[x]` und `2026. war ein Jahr` mitten im Absatz unverändert. ## Ergebnis

`parseMarkdown` kennt den Block `ol`: Zeilen `^\d+\. ` am Zeilenanfang bilden eine nummerierte Liste, eine Zahl mitten in einem offenen Absatz beginnt nur mit `1.` eine (wie CommonMark), sonst bleibt sie Text. Der Zustand führt die Listenart, ein Wechsel `-` ↔ `1.` schließt die offene Liste. `[ ] `/`[x] ` am Punktanfang wird ☐/☑, im Fließtext bleibt es. `MarkdownView` rendert `ol`.

## Schritte

1. `git fetch --prune`, `git merge origin/main` in `sprint/ru71`; Konflikte lösen (Index-Konflikte in `docs/backlog` mit `-X ours`, danach `plan_index` dry false).
2. Diff lesen: `git diff --stat origin/main...HEAD`, dann je Session die geänderten Dateien gegen ihre Erlaubten Dateien abgleichen.
3. Reviewer-Agenten im Hintergrund starten (Kontext), parallel `task check:all` blockierend; Nachweis AC-01 zusätzlich: `git ls-files '*.go' go.mod go.sum '**/go.mod' '**/go.sum' .golangci.yml '**/.golangci.yml'` leer.
4. Stichprobe MCP über die laufende Rust-Workbench und das Rust-Studio: `workbench_status`, `plan_list {status: "aktiv"}`, `check_run task:check:diff`, im Studio `world_list` (AC-04).
5. Schwere Befunde beheben, danach betroffene Prüfungen gezielt wiederholen.
6. `docs/glossar.md` anpassen (Kontext).
7. Sprint-README › Abnahme füllen (höchstens fünf Zeilen): Datum, Kriterien AC-01 bis AC-04 mit Verweis auf RU71.1–RU71.5, behobene Befunde, keine neuen Tickets (Befunde für den Hauptrechner), Abnahme-Ticket B-1295 (PC-Abnahme durch Ralf, danach).
8. Ergebnis dieser Session, Status `fertig`; Sprint `plan_set {id: "RU71", fields: {Status: "erledigt"}}`. Ein Commit, Push.
9. PR gegen `main`: `gh pr create --base main --head sprint/ru71` mit Titel „RU71: Go restlos entfernt, Werkzeuge in Rust und TypeScript“ und Text mit Sessions, Kriterien, Tag `go-werkzeuge-final` und Hinweis auf B-1295; `gh pr merge --squash --auto`; warten bis gemergt.
10. Nach dem Merge: `git merge origin/main`, `.work/` aufräumen, gemergten Branch lokal entfernen.

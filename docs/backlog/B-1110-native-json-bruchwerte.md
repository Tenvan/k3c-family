## Ausgangslage

`k3c_data::native::Native` hat `i64`-Felder, Go liest `data/native.json` als `float64`. Ein Bruchwert (4.5) gilt in Rust als unlesbar (Standardwerte), in Go nicht; ein ausdrückliches `slowLogEverySeconds: 0` ist von „fehlt“ nicht zu unterscheiden (Rust 5 s, Go 0). Die Datei enthält zurzeit nur ganze Zahlen, kein akuter Fehler. Gefunden in RU29.2 (Chronik).

## Ziel

Rust liest `native.json` wie Go.

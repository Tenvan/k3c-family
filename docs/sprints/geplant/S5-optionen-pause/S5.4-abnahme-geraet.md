## Nicht-Ziele

Code ändern, Mängel beheben (jeder Mangel wird ein Ticket), Abnahme von Audio oder Juice.

## Schritte

1. 🧑 startet den Server mit dem aktuellen `main` und öffnet das Spiel am TV (Edge auf der Xbox, Controller) und am Handy.
2. TV, Controller: im Spiel Menu kurz drücken → Szene öffnet. Musik auf 0 %, SFX auf 50 %, Screenshake aus, Flash aus, Farbschwäche-Symbole an; mit Menu schließen. B drücken (nichts geschieht in der Szene). View + Menu halten → Landingpage. Seite neu laden, Szene öffnen: Werte unverändert.
3. Handy, Touch: Schaltfläche zum Öffnen tippen, alle Einträge antippen, schließen, Seite neu laden, Werte prüfen.
4. Tastatur (PC): Esc öffnet und schließt, Pfeile und Enter bedienen die Einträge.
5. Sprache auf English stellen: alle Szenen durchgehen (Lobby, Spiel mit HUD, Optionen, Verbindungsmeldungen), Texte auf Sinn, Rechtschreibung und Lesbarkeit prüfen (nichts abgeschnitten), neu laden, Sprache bleibt. Zurück auf Deutsch.
6. Ergebnis hier eintragen: Datum, Geräte, je Kriterium `abgenommen` oder Mangel mit Ticket; Wahl beim Sprachwechsel (sofort oder nach Neuladen) bestätigen oder ändern. `Status: fertig`, Tabelle der Sprint-README anpassen.

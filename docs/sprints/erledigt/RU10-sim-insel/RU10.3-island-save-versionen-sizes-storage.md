`island_sizes.go`: Daten-Lader und Prüfung (`loadIslandSizes`, `mustIslandSizes`) liegen seit RU3 in `k3c_data::island_sizes`; nicht neu schreiben. Gos Paket-Variable `islandSizes` wird Parameter (`&IslandSizesFile`).

`island_storage.go`: `stockField(s, resource) -> Option<&mut i64>` (Go gibt `*int`; in Rust die Auswahl per `match` auf den Ressourcen-Namen; ersetzt Platzhalter `stock_field`), `capacity(w)`, `purseMax(w)` (ersetzt `purse_max`; `state/purse.rs` aus RU8 ruft ihn), `depositPoint`, `carryToStock(w, ti, isl, dt)` (ersetzt `carry_to_stock`), `resourceFull(w, resource)` (ersetzt `resource_full`), `addStockCapped`. In einer Insel ist der Vorrat `w.stock` (Stufen tauschen ihn per `swap`, RU10.1); die Funktionen lesen daher nur `w.stock`, nie `isl.stock` (Zustandsmodell Entscheidung 5: wer beides zugleich braucht, legt ein Ticket an).

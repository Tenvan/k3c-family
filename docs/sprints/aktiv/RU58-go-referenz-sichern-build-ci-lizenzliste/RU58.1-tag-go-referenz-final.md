## Ziel

Der Git-Tag `go-referenz-final` steht auf `origin` und zeigt auf einen Stand, aus dem sich das Go-Spiel jederzeit bauen lässt; `docs/standards/go-referenz.md` sagt in wenigen Schritten, wie.

## Kontext

Ralf hat am 2026-11-19 entschieden, das Go-Spiel (`native/k3c-game`, Go + Ebitengine) zu entfernen (RU37). Es ist das Orakel für Bildvergleich und Messwerte des Rust-Spiels (B-1120, B-1129, B-1130, RU36). Damit es danach nicht verloren ist, bekommt der letzte Stand mit Go-Spiel einen Tag. Es gibt bisher keinen Tag `go-*` (Tags: `v0.5.0` bis `v0.8.1`).

Bau des Go-Spiels heute (zum Nachprüfen in dieser Session): Namensraum `native` (`native/Taskfile.yml`): `task native:game:exe` baut `native/k3c-game/bin/k3c-game.exe`; Grafik kommt aus `task gen:paper` (nicht eingecheckt, B-737); Go aus `native/k3c-game/go.mod`; Paket `task native:game:build` nach `dist/k3c-game-go/`. Das Rust-Spiel bleibt davon getrennt (`rust/`).

Der Tag zeigt auf `origin/main` zu Beginn der Session; spätere Commits auf `main` ändern am Go-Code nichts, bis RU37 ihn löscht.

## Erlaubte Dateien

- `docs/standards/go-referenz.md` (neu)

## Nicht-Ziele

Go-Code ändern oder löschen. Aufnahmen und Messungen (RU58.2, RU58.3). Einen Release anlegen.

## Schritte

1. `git fetch --prune --tags`; `git rev-parse origin/main` notieren. Sicherstellen, dass `native/k3c-game/go.mod` dort liegt.
2. Annotierten Tag setzen und pushen: `git tag -a go-referenz-final origin/main -m "Letzter Stand mit Go-Spiel (Referenz für Bildvergleich und Messwerte, Ralf 2026-11-19)"`, dann `git push origin go-referenz-final`. Der Tag wird nie verschoben oder gelöscht.
3. Bau aus dem Tag nachweisen, nur in `.work/`: `git worktree add .work/go-referenz go-referenz-final`; darin `bun install --frozen-lockfile`, `task gen:paper`, `task native:game:exe`; `native/k3c-game/bin/k3c-game.exe` muss entstehen und mit `--version` oder kurzem Start (Fenster schließen) laufen. Schlägt der Bau fehl, hält die Session an (`blockiert`, Fehler ins Ergebnis).
4. `docs/standards/go-referenz.md` schreiben (≤ 60 Zeilen): Zweck, Tag und Commit, die Befehle aus Schritt 3 (Worktree in `.work/`, Bau, Aufnahme `K3C_GAME_EXE=<exe> K3C_E2E_OUT=<ordner> go test ./e2e -run TestFlowImages` in `native/k3c-game`, Messung `tools`- bzw. `native/measure.ps1 -Engine game`), Hinweis "nach RU37 fehlt `native/` im Arbeitsbaum: nur im Tag-Worktree", Hinweis auf die gesicherte Referenz (RU58.2, RU58.3).
5. Worktree `.work/go-referenz` entfernen (`git worktree remove --force`), `.work/`-Reste löschen.
6. Ergebnis, Status `fertig`, ein Commit, Push auf `sprint/ru58`.

## Ziel

Rechts im Asset-Studio steht auf allen Seiten ein ein- und ausblendbarer Chat (assistant-ui), der Nachrichten über das Backend aus WZ19.1 schickt und die Antwort fortlaufend zeigt (AC-03, Teil Chat); die neue Abhängigkeit ist mit Lizenz, Größe und React-Version belegt.

## Kontext

Spec: `B-488 › Anforderungen` („Ein allgemeiner Chat rechts im Studio …“), `B-488/AC-08`; Sprint-README WZ19 (Anforderungen, Ausnahme- und Fehlerfälle). 🧑 hat die neue Abhängigkeit assistant-ui am 2026-10-19 im Chat mit der Spec freigegeben; die Session belegt trotzdem Lizenz, Größe (Bundle-Zuwachs von `task studio:frontend`, vorher und nachher) und die Verträglichkeit mit React 19.3 (Peer-Abhängigkeiten) im Ergebnis. Passt eins nicht (z. B. Lizenz nicht frei, React-Version unverträglich): `Status: blockiert`, Ticket vom Typ `Frage`, aufhören.

Frontend `tools/k3c-studio/frontend/` (eigenes `package.json` mit React 19.3, Radix Themes, Vite, Vitest; Lockfile `package-lock.json`): `src/App.tsx` (Seiten-Rahmen, 52 Zeilen), `src/ui/Splitter.tsx`, `src/lib/prefs.ts` (gemerkte Einstellungen), API `src/api/` (`http.ts` für RPC und Ereignis-Strom, `mock*.ts` für Tests, `types.ts` mit 364 Zeilen nahe der Grenze: Chat-Typen in eine eigene Datei). Backend-Methoden und Strom aus WZ19.1 (`tools/k3c-studio/backend/chat_*.go`, bis TS1.1 `engine/studio/chat_*.go`). assistant-ui mit eigener Laufzeit an das Backend binden (z. B. `useLocalRuntime` mit eigenem Adapter oder `ExternalStoreRuntime`); die Skills `assistant-ui:*` helfen bei der Einbindung.

Fehlerfälle aus der Sprint-README im Chat sichtbar: CLI fehlt oder nicht angemeldet → Meldung; Zeitlimit oder Abbruch → Antwort als abgebrochen markiert; Verlauf nicht beschreibbar → Hinweis.

**Notiz (2026-10-20, B-507, TS1.5; Spec-Kriterien unverändert, Entscheidung offen in `B-488 › Offene Fragen`):** Der Chat steht **global rechts in allen Studio-Seiten**, die Seite Welten Editor zuerst. Die Anbindung der Provider läuft **nur über CLI und ACP** (Agent Client Protocol); das Studio erkennt verfügbare Provider automatisch und legt sie 🧑 zum Verbinden vor. Das Studio ist seit TS1 nur ein eigenes Fenster (keine Seite des Spielservers, `docs/decisions/004-studio-getrennt-datei-watch.md`); `task build` baut kein Studio mehr, das Frontend prüft `task check:studio`.

## Ziel

Eine gekennzeichnete Truhe ist bei mindestens zwei gesteuerten Monarchen eine Doppel-Truhe: sie öffnet nur, wenn beide gleichzeitig davorstehen, und wirft mehr Gold als Fontaene aus; Solo bleibt sie eine normale Truhe (B-968, Sim-Teil).

## Schritte

1. `data/coop.json` und Struct `CoopFile` in `k3c-data` (Werte > 0 prüfen, Test).
2. Modul `k3c-sim/src/coop/` mit `is_double_chest(seed, stage, pos, every_nth)` (deterministisch, im Mittel jede n-te Truhe) und Wirksamkeit: nur bei mindestens zwei gesteuerten Monarchen, nur wenn die Welt in `coop.json` steht.
3. In `economy/players.rs` an der Truhe: Solo wie bisher (normales Gold); Koop: Truhe bleibt zu, bis zwei gesteuerte Monarchen derselben Stufe im selben Tick im Aufheb-Radius stehen; dann Gold = normales Truhen-Gold x `goldFactor` über die vorhandene Fontaene, `chest_skill_point` für beide.
4. Zustand: je wartender Doppel-Truhe der wartende Monarch (Index), damit RU62.4 das leuchtende Schloss zeichnet; Feld `double` je Truhe, nur wenn das Kennzeichen wirkt.
5. Ausnahmen: Spieler geht oder kommt (Truhen wechseln ohne Übergang), Monarch ohne Krone zählt mit, verschiedene Stufen bleiben zu, mehr als zwei Spieler: zwei genügen, Stufe ohne Truhe hat keine Doppel-Truhe.
6. Tests (Rust, `coop/*_tests.rs`): Solo normal, Koop wartet, Koop öffnet mit Gold x Faktor und Zusatz für beide, Spielerzahl sinkt auf eins, gleicher Seed gleiche Kennzeichen, Golden unverändert.

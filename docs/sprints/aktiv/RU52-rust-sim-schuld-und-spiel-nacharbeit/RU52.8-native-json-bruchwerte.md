## Ziel

Rust liest `data/native.json` wie Go: Zahlenfelder als `f64`, ein ausdrückliches `0` ist von „fehlt“ unterscheidbar (B-1110).

## Kontext

`k3c_data::native::Native` hat `i64`-Felder, Go liest `float64`. Ein Bruchwert (4.5) gilt in Rust als unlesbar (Standardwerte); `slowLogEverySeconds: 0` ist von „fehlt“ nicht zu unterscheiden (Rust 5 s, Go 0). Die Datei enthält heute nur ganze Zahlen, die Werte bleiben unverändert. Gefunden in RU29.2.

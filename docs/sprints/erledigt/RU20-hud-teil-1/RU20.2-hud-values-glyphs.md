## Ziel

Die Anzeige-Werte des HUD (`values`: Uhr, Gold, Vorrat, Hub, Bürger, Kampf, Reise, Ort) und die Tasten-Glyphen mit Beschriftung und Farben (`glyphs`) rechnen in Rust wie in Go.

## Kontext

Leitfaden `docs/standards/rust-port.md` zuerst lesen. Vorhanden aus RU20.1: `hud/mod.rs`, `texts.rs` (`tr`, `tf`, `name_of`, `Arg`), `data.rs`, `fonts.rs`, `layout.rs`.

**Quellen** in `native/k3c-game/hud/`: `values.go` (319, Test `values_test.go`: 7 Tests), `glyphs.go` (233, Test `glyphs_test.go`: 7 Tests). Ziel: `hud/values.rs`, `values_tests.rs`, `glyphs.rs`, `glyphs_tests.rs`; `values.rs` bei > 400 Zeilen am Abschnitt `merchantText` teilen (`values_texts.rs`).

**values.** Jeder Anzeigetext hat einen Schlüssel (`clockKey`, `goldKey`, `stockKey`, `hubKey`, `waveKey`, `travelKey`, `placeKey`) und einen Text-Bauer (`clock_text`, `gold_text`, `shared_text`, `hub_text`, …): reine Funktionen über Werte, Schlüssel sind `#[derive(Clone, PartialEq)]` Strukturen. `memo[K comparable]` (Go: Zwischenspeicher für den zuletzt gebauten Text je Schlüssel, „Memo baut nur bei neuem Schlüssel“) wird `struct Memo<K: PartialEq + Clone> { key: Option<K>, text: String }` mit `fn get(&mut self, k: K, build: fn(&K) -> String) -> &str`; Test `memo_baut_nur_bei_neuem_schluessel` zählt Aufrufe. `format_time(seconds)` (Minuten und Sekunden), `new_clock_key(lang, c: &CycleInfo, speed, aggression: Option<f64>, saved)`, `gold_flash` (`GoldFlash::step(gold, now) -> bool`, `GOLD_FLASH_SECONDS = 0.8`), `resource_order` (`wood`, `stone`, `copper`, `iron`, `crystal`), `stock_of(&Stock) -> [i64; 5]`, `new_hub_key(lang, e: &Economy, m: Option<&Merchant>)`, `new_travel_key(lang, t: Option<&Travel>)`. `Economy` ist der Typ aus `crate::props::pending` (RU16.1; bis RU18 dort, danach `k3c_sim`); `CycleInfo`, `Merchant`, `Travel`, `Stock` kommen aus `k3c_sim::state`. Go-`*float64` (aggression) ist `Option<f64>`. Rechenreihenfolge und Rundung (`math.Round`, `int(...)`) wie Go.

**glyphs.** `Glyph { key, label, icon }` mit `new_glyph(key, label)` (ruft `icon_asset(key, label)`, steht in `glyphs.go`), Tabellen `glyph_actions`, `key_actions`, `pad_glyphs`, `pad_labels`, `glyph_colors` (je `[[u8; 4]; 2]`), `key_name(layout, action)`, `key_label(lang, name)` (`pub`), `pad_label(lang, action)`, `glyph_of(lang, action, profile)`, `slot_labels(lang, profile) -> [String; 6]`, `join_text(lang, unseated: &[DeviceId])`, `JoinKey`, `new_join_key`, `join_from_key`. Nur **Xbox-Symbole** und Tastenkappen (AC-02): kein Geräte-Familien-Zweig über Xbox hinaus, `TestBUndViewNieAlsGlyph` bleibt (B und View werden nie als Glyphe angeboten). `DeviceId` aus `src/view`. `slices.Contains` wird `contains`, `utf8.RuneCountInString` `chars().count()`.

**Tests.** `TestSchriftrollen` (in `glyphs_test.go`) prüft `fonts.rs` aus RU20.1. `TestMenuFooterPerDevice` ruft `menuLine` (Datei von RU23, `skilltext.go`): `#[ignore = "wartet auf RU23"]`, RU23 schaltet ihn ein. Alle übrigen laufen.

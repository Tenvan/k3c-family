## Kontext

- Spec: `docs/backlog/archiv/B-046-dev-mcp.md` › Anforderungen (Eigenes Log, Log-Leser, Verdichtung, Log-Tools, Katalog ›
  Instructions), Beispiele, Fehlerfälle. Stand nach M1.2: Katalog, Zähler, `check_run`, `internal/console`.
- `internal/applog`: `slog.New(slog.NewJSONHandler(…))` in eine Datei, zusätzlich jede Zeile als Strom `log` in den
  Konsolenpuffer `k3c-dev` (kleiner eigener Handler, der an beide weitergibt). Nicht beschreibbarer Ordner → nur Puffer,
  eine Meldung auf stderr.
- `internal/logs`: Rückwärts-Leser in 1-MB-Blöcken (kein `bufio.Scanner`), Budget 8 MB, Filter (Level-Rang
  `DEBUG` < `INFO` < `WARN` < `ERROR`, unbekanntes Level zählt als niedrigstes), `since` als Dauer oder RFC 3339,
  Vorwärts-Leser ab Byte-Cursor mit `gekürzt`, Fingerabdruck und Gruppen. Unlesbare Zeilen überspringen und zählen.
- Log-Quellen = alle `logs/*.jsonl` (Name ohne Endung) plus die Konsolen-Quellen aus M1.2. Beispieldateien für Tests
  in `internal/logs/testdata/` (erfundene Einträge, mit kaputter Zeile, UUID, Pfad, Zahl und Text in Anführungszeichen).
- `instructions.md` (per `//go:embed` in die Server-Optionen): kurz, welches Tool wofür, dass `check_run`
  `npm run check`/`npm test`/`go test` in der Shell ersetzt und `logs_*` statt Dateilesen.

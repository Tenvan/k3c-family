## Ziel

Das Gerüst des Crates `k3c-balance` steht, und die einfachen Bots aus `bots.go` (passive, saver, walls, economy, coop) entscheiden in Rust wie in Go.

## Kontext

Leitfaden `docs/standards/rust-port.md` zuerst lesen, dazu `docs/standards/rust-sim-zustand.md` (wie Welt, Spieler, Bauplatz in Rust heißen und referenziert werden). Quelle: `engine/balance/bots.go` (343; kein eigener Test, geprüft über `balance_test.go`, `mix_test.go`, `profiles_test.go` in RU25.4/RU25.5). Ziel: `rust/crates/k3c-balance/src/bots.rs`. Der Crate existiert schon als leeres Gerüst (`Cargo.toml` mit `k3c-sim`, `k3c-data`; `lib.rs` nur mit Test `crate_baut`).

**Diese Session legt an:** `lib.rs` mit den `pub mod`-Zeilen (Paket ohne Gruppen, Leitfaden § 2: `engine/balance/name.go` → `src/name.rs`), `src/fehler.rs` (`enum Fehler` des Crates, Meldungstexte wie Go), `src/pending.rs` (Platzhalter, Leitfaden § 7) und `src/testutil.rs`. `Cargo.toml` bekommt bei Bedarf `k3c-det`, `k3c-rng`, `k3c-level`, `k3c-room` und die Workspace-Abhängigkeiten `serde`, `serde_json`.

**Vorentscheidungen:**
- `type Bot func(w, p) PlayerCommand` wird `pub enum Bot { Passive, Saver, Walls, Economy, Wirtschaft, Coop, Descent { inner: Box<Bot>, deepest: i64 }, BossFight { inner: Box<Bot>, deepest: i64 } }` mit `pub fn decide(&self, isl: &Island, w: &World, p: &Player) -> PlayerCommand`. Die Insel, die Go in `withDescent`/`withBossFight` einfängt, kommt als Parameter (kein Verweis im Wert, Leitfaden § 4). Die Zweige `Wirtschaft`, `Descent`, `BossFight` rufen bis RU25.2/RU25.3 Platzhalter in `pending.rs`.
- `var bots = map[string]Bot` wird `fn bot_by_name(name) -> Option<Bot>` mit `match`; `bot_names()` liefert die Namen sortiert wie Go (`slices.Sorted(maps.Keys)`). `minPlayers` als `match`.
- `var prices = must(loadPrices(data.Files))` wird `fn prices() -> &'static PriceList` mit `std::sync::OnceLock`, gelesen aus `k3c_data::Source::from_env()`; `OnceLock` ist nur für solche einmal gelesenen Daten erlaubt (wie Gos Paket-Variablen).
- `*sim.Site`, `*sim.Troop` als Rückgabe („kann fehlen“) werden `Option<&Site>` bzw. der Index nach `rust-sim-zustand.md`; `math.Abs` → `abs`.
- Gewürfelt wird hier nicht; fehlt ein Sim-Typ, ist das ein Ticket (die Sim ist seit RU22 vollständig).

## Ziel

Planungsseite und MCP-Tool `gh_status` zeigen je Sprint PR, CI und Merge-Status sowie den letzten CI-Lauf auf `develop`.

## Kontext

- Quelle: GitHub CLI `gh` (bei 🧑 angemeldet). Aufrufe:
  `gh pr list --state all --base develop --limit 50 --json number,title,state,isDraft,headRefName,mergeable,mergeStateStatus,statusCheckRollup,url`
  und `gh run list --branch develop --limit 1 --json status,conclusion,displayTitle,url,createdAt`.
- Prozesse nur über `tools/k3c-dev/internal/proc` (`proc.Command` mit Kontext und Timeout, Muster in `internal/planning/worktree.go`), Arbeitsordner = Repo-Wurzel.
- Zuordnung: Branch `sprint/<präfix>` ↔ Sprint-ID (`strings.EqualFold`); je Sprint der neueste PR.
- CI aus `statusCheckRollup`: alle `SUCCESS`/`NEUTRAL`/`SKIPPED` → grün, ein `FAILURE`/`CANCELLED`/`TIMED_OUT` → rot, sonst läuft. Merge: `mergeable` `MERGEABLE`/`CONFLICTING`/`UNKNOWN`.
- Die Planungsseite aus M8.2 liegt in `frontend/src/planning/`; Binding neben `PlanningData` in `app_planning.go`.

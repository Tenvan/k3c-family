## Ziel

Matrix, Einzellauf, parallele Läufe und Fortschritt laufen in Rust wie in Go; ein fester kurzer Lauf eines Bots trifft dieselben Entscheidungen wie Go.

## Kontext

Leitfaden `docs/standards/rust-port.md` zuerst lesen. Quellen in `engine/balance/`: `run.go` (190: `Matrix`, `Scenario`, `Result`, `Report`, `Scenarios`, `Run`, `runOne`, `newIsland`), `parallel.go` (92, T: `Crash`, `runAll`, `tickProgress`), `progress.go` (250, T). Tests dazu ohne eigene Quelle: `balance_test.go` (Matrix), `mix_test.go` (Mischung je Spieler). Ziel: `rust/crates/k3c-balance/src/run.rs`, `parallel.rs`, `parallel_tests.rs`, `progress.rs`, `progress_tests.rs`, `balance_tests.rs`, `mix_tests.rs` (die beiden letzten als `#[cfg(test)] mod …;` in `lib.rs`).

**Vorentscheidungen:**
- `enginetools.TickHz` wird `pub const TICK_HZ: i64 = 30` in `run.rs` (der Crate hängt nicht von `k3c-game` ab); `dt = 1.0 / TICK_HZ as f64` wie Go.
- `runOne` fängt eine Panik (`recover`) mit `std::panic::catch_unwind(AssertUnwindSafe(…))`; Text `abgebrochen: <Meldung>` wie Go.
- **Threads:** `parallel.rs` ist die einzige Stelle im Crate mit Threads: `std::thread::scope` mit `available_parallelism()` Arbeitern (Go `runtime.NumCPU()`), Ergebnisse landen nach Index im `Vec` (Reihenfolge wie Go), Fortschritt über `std::sync::mpsc` an den aufrufenden Thread (kein `Mutex`). `Crash { value: String, stack: String }`; `stack` bleibt leer (Rust hat an der Fangstelle keinen Stack der Panik), die Meldung ist gleich.
- Kennzahlen (`newCollector`, `observe`, `result`, `Metrics`) kommen erst mit RU28.1: Platzhalter in `pending.rs`. Tests, die Kennzahlen brauchen, bekommen `#[ignore = "wartet auf RU28"]`; laufen müssen schon `TestMatrixPrueft`, `TestUngueltigerLaufMitSeed`, `TestMischungUngueltig` und die Tests von `parallel_test.go`.
- Ein „fester Lauf“ für AC-01 ist ein Test mit den kleinsten Werten aus `balance_test.go` (ein Seed, ein Tag); er ist kein Balancing-Lauf (Ausnahme B-1014 für Tests). Die Entscheidungen je Takt vergleicht der Test über den Replay-Datensatz (`Replay.record`, RU25.5); bis dahin `ignore = "wartet auf RU25.5"`.

## Ziel

`tools/k3c-studio` ist ein eigenes Go-Modul, enthält die Studio-Pakete und den MCP-Server `k3c-studio` mit den Tools world_*, assets_*, hub_*, level_generate; headless startbar und per Tests geprüft.

## Kontext

Nach WZ63.1 liegt gemeinsamer Code in `tools/workkit`. Studio-Pakete in der Workbench: `internal/world` (3,5k Zeilen), `assetsui`, `paperassets`, `review` (nur von assetsui/paperassets genutzt), `studioview`, `hubplan`. Tools: `internal/mcpsrv/tools_world*.go`, `tools_assets*.go`, `tools_hub.go`, `level_generate` in `tools.go`, dazu deren Tests und `testdata`. Binding-Dateien der App: `app_world.go`, `app_assets.go`, `app_studio.go`, `app_hub.go`. Workbench-`App` (Wails) und `headless.go`/`main.go` sind Vorlage für das Studio-`main`. Studio importiert `k3c` (Engine, für level_generate), `k3c/tools/assetkit`, `workkit`; nie die Workbench.

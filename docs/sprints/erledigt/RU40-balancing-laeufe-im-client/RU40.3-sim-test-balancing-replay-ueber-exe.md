## Kontext

Schnittstelle `docs/standards/k3c-game-laeufe.md`, Starter `tools/k3c-workbench/internal/gameexe` (RU34.1). Heute: `internal/simrun/offline.go` (179: `Proc`, `Result`, `Offline`, `procOutput`, `runEngine` über `simcli.Stream`; Naht `Registry.Exec` in `registry.go`, Standard `runEngine`), `internal/simrun/spec.go` (`Spec.args`: Argumente von `balance --targets …`), `internal/mcpsrv/simtest.go`, `simtest_spec.go` (Tool `sim_test`, Schema), `internal/mcpsrv/tools_replay.go` (127: `replayRun` über `simcli.Call(["balance","--play",path])`), Beschreibung in `internal/mcpsrv/tools.go` (`registerEngine`). Tests: `internal/simrun/offline_test.go`, `internal/mcpsrv/tools_replay_test.go`, `simtest*_test.go`.

**Vorentscheidungen:**
- `runEngine` wird `runExe`: `gameexe.Stream(ctx, p.Dir, "balance", args, opts, on)` mit `p.Args` ohne das führende `balance`; Zeilen gehen wie bisher an `p.Out("stdout"|"stderr", text)`; Ende nach eigenem Stop → `Result{Exit: 130}`, Zeitlimit → `TimedOut`. `Registry.Exec` zeigt auf `runExe`. `Spec.args` bleibt (dieselben Flags).
- `Spec` bekommt `Head bool` und `Speed int` (`json:"head,omitempty"`, `json:"speed,omitempty"`): `--window [--speed N]`. Mit `head` läuft höchstens ein Lauf zugleich (Plätze der Registry: mit Fenster 1).
- `sim_test` rechnet mit der EXE des Checkouts aus `checkout`; die Sim-Sperre (`simLockErr`, Lock-Datei) bleibt unverändert vor allem anderen.
- `replay_run` bekommt `head`/`speed`, ruft `gameexe.Call(ctx, root, "balance", ["--play", path], opts)`; `ownCheckoutErr` entfällt, das Tool nimmt `checkout`. `tools_replay_test.go` nutzt statt `simcli.Stream` eine Fake-Engine bzw. die Fixture `balance-play` aus `testdata/rust/runs/`.
- Tests ohne echte Läufe: Fake-EXE über die Naht `Registry.Exec`/Paket-Variable; ein Test mit echter EXE nur für `--help`-artige Aufrufe (`sim balance --flag-falsch` → Exit 2), wenn die EXE frisch ist.
- Danach importiert nur noch `internal/studioview/game.go` und `internal/world/override.go` etwas aus `k3c/engine/*` außer `conlog`/`devrun` (RU40.4).

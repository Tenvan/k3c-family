### Vorentscheidungen (Claude, nach Leitfaden)

1. **Abhängigkeiten jetzt eintragen** (Workspace, exakt wie Spike-Lockfile): `rmcp = { version = "=3.11.0", features = ["server", "macros", "transport-streamable-http-server"] }`, `schemars = "=1.2.3"`. In dieser Session nur die Modelltypen `rmcp::model::{CallToolResult, Content, JsonObject}` und `rmcp::ErrorData`.
2. **Konstanten** wortgleich: `CHECKOUT_ARG = "checkout"`, `HEADER_ROOT = "X-K3C-Root"`, `ARGS_RUNES = 200`, `TEXT_RUNES = 120`, Ringlänge 200, `PANIC_TEXT` (aus `observe.go`, für RU66.4 schon hier). Die Beschreibung des Arguments `checkout` aus `withCheckout` Zeichen für Zeichen.
3. **Zeitformat** `TimeLayout` (`2006-01-02T15:04:05.000Z07:00`) ist dasselbe wie die JSON-Zeit von `applog`: eine gemeinsame `pub fn` in `logger` (z. B. `logger::time_millis(&DateTime<Local>) -> String`, bei Offset 0 `Z`), falls RU66.1 sie noch privat hat, dort öffentlich machen.
4. **`stats`:** `ToolStats`, `Call`, `Snapshot`, `Outcome` mit serde-Namen exakt nach den `json:`-Tags (`avgMs`, `lastCall`, `startedAt`, `startSeq`, `durationMs`, `error` und `target` mit `skip_serializing_if = "String::is_empty"` wie `omitempty` …). `Stats::new(now: usage::Clock, on_start, on_call, target)` mit `Option<Arc<dyn Fn(&Call) + Send + Sync>>` bzw. `Option<Arc<dyn Fn(&str, &str) -> String + Send + Sync>>`; Methoden `register`, `begin`, `end`, `observe_clients`, `calls`, `snapshot`, `uptime`; intern ein `Mutex`.
5. **`text`:** `clip_args`, `clip`, `ref_name(id: i64)` (Go `Ref`, Multiplikation wie Go mit `u64` und Maske `0xfffffff`, Format `{:07x}`), `or_dash`, `text_result(text, is_error) -> CallToolResult`, `result_text(&CallToolResult)` (nur Text-Inhalte, mit `\n` verbunden), `outcome_of(&Result<CallToolResult, ErrorData>) -> Outcome` (Fehler → `Outcome{err: message}`).
6. **`workspace`:** `#[derive(Clone, Debug, PartialEq)] pub struct Workspace { pub root: PathBuf, pub name: String }` mit `source`, `console_source`, `own_source`, `label`, `short` (Texte wortgleich); `same_path`, `same_dir`, `canon` (Windows: `std::fs::canonicalize` plus Entfernen des Präfixes `\\?\`, eigene Hilfsfunktion, kein `dunce`; Regel B-628 „längster vorhandener Anfang, Rest angehängt“ wie Go), `is_worktree_of`, `find_root` (1:1: sucht aufwärts das `go.mod` mit `module k3c`; der Wechsel des Markers gehört zu RU71, im Ergebnis vermerken).
7. **`checkout`:** Go hängt die Zuordnung an `Server`; Rust trennt sie in `pub struct Resolver { root: PathBuf }`: `resolve_header(header: Option<&str>) -> Result<Workspace, String>` (Go `resolveWorkspace` ohne Request), `async resolve_checkout(&self, value: &str)`, `async worktrees(&self) -> Result<Vec<PathBuf>, String>` (git über `proc::Cmd`, `git worktree list --porcelain` wie Go), `workspace_of(dir)`, `worktree_names`. Freie Funktionen `split_checkout(args: Option<JsonObject>) -> Result<(String, Option<JsonObject>), String>` und `with_checkout(schema: &mut JsonObject, names: &mut Vec<String>)` (Eigenschaft `checkout` vom Typ string mit der Go-Beschreibung, Namen sortiert). Fehlertexte wortgleich zu Go.
8. **`paths::inside_root(root, name) -> Result<PathBuf, String>`** und **`writeguard::WriteGuard`** (Felder und Texte aus `writeguard.go`): `EvalSymlinks` wird `canonicalize` (Präfix entfernen); Reparse-Punkte (Junctions) über `std::os::windows::fs::MetadataExt::file_attributes() & 0x400` aus `symlink_metadata`, ohne `unsafe`.
9. **`canon_tests.rs`** nur `#[cfg(windows)]`: Den Kurznamen holt der Test ohne `unsafe` über `cmd /c for %I in ("<lang>") do @echo %~sI`; ohne `~` im Ergebnis überspringt er wie Go (Test endet ohne Prüfung, Meldung per `eprintln!`).
10. **Tests mit Git** (`checkout_tests.rs`, neu, weil Go das über die Workbench testet): ein Repo samt `git worktree add` unter `testutil::tmp_dir()`; Worktree-Name, absoluter Pfad, unbekannter Name (Fehlertext nennt die Worktrees), `split_checkout` mit Text, Nicht-Text und ohne Feld.

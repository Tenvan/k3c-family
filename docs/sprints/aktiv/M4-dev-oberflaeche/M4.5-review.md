## Ziel

M4 ist nach der leichten Review-Session und der Abnahme des Fensters durch 🧑 abgenommen und liegt unter
`docs/sprints/erledigt/`.

## Kontext

- Ablauf: `docs/arbeitsweise.md` › Review-Session (nur Diff, nur schwere Fehler). `Start-Commit` steht in der
  Sprint-README. Ein günstiges Modell reicht; mehrere Reviewer je Bereich parallel, wenn 🧑 das erlaubt
  (Vorschlag: Wails-App/Lebenszyklus, Dienste-Seite, Logs-Seite).
- Schwere Fehler hier vor allem: Fenster schließen beendet eigene Dienste nicht oder übernommene doch; Stopp eines
  übernommenen Dienstes ohne Dialog; ein Quellname aus dem Frontend wird ungeprüft zum Pfad; Konsolen- oder Logtext
  landet als HTML im DOM; Goroutinen oder Ereignisse laufen nach dem Schließen weiter; ein zweiter Start öffnet ein
  zweites Fenster oder einen zweiten MCP-Server; ungeordnete `service:state` überschreiben neuere Zustände;
  Zugriff auf `localStorage` wirft und die Oberfläche bleibt leer.
- **Abnahme durch 🧑 (AC-07):** 🧑 startet `k3c-dev.exe` und stellt nach: B-064 › Beispiele und Fehlerfälle
  (`check_run npm:test` erscheint blau und wird grün/rot, Konsole läuft mit; `WARN`-Filter; zweiter Start; belegter
  Port), B-068 › Beispiele (Vite läuft, Heimnetz gestoppt; `Alle stoppen`), Größe und Position nach Neustart, beide
  Farbmodi. Der Agent schreibt diese Liste zum Abhaken in das Ergebnis und bittet 🧑 darum.

## Erlaubte Dateien

- Alle im Sprint geänderten Dateien (nur schwere Befunde beheben)
- `docs/sprints/`, `docs/backlog/`

## Nicht-Ziele

Stil, Doku, Vereinfachungen; neue Seiten oder Funktionen; MCP-Seite (M5).

## Schritte

1. `npm run check:dev`, `npm run check`, `npm run check:go` → grün.
2. `git diff <Start-Commit>..main` lesen und nach den schweren Fehlern oben suchen.
3. Befunde beheben bzw. als Ticket anlegen.
4. 🧑 um die Abnahme AC-07 bitten (Liste oben). Ohne Bestätigung: `Status: blockiert`, Grund im Ergebnis, aufhören.
5. Abnahme (höchstens fünf Zeilen) ausfüllen; B-064 und B-068 auf `erledigt` (Ticket und Index), wenn alle Kriterien
   belegt sind; B-069 prüfen (CI-Job nach dem Push von 🧑 grün?).
6. `git mv docs/sprints/aktiv/M4-dev-oberflaeche docs/sprints/erledigt/`, `Status: erledigt`, Fahrplan anpassen,
   lokal mergen.

# Icon des Spiels
Goldene Krone auf nachtblauem Grund (`appicon.png` 256 px, `icon.ico` 16, 32, 48, 256 px), erzeugt von
`tools/icons/gen_icons.py`. Noch nicht in `k3c-game.exe` eingebettet: das braucht eine Windows-Ressource (Crate
`winresource` im Build-Skript, neue Abhängigkeit, Entscheidung offen) oder das Fenster-Icon zur Laufzeit.

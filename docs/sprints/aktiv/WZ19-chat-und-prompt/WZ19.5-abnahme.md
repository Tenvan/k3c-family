## Ziel

🧑 hat am PC eine per Chat gefüllte Welt mit mindestens zwei Inseln als ungespeicherten Entwurf abgenommen und sie im Spiel gestartet (AC-04, `B-488/AC-09` Teil Chat).

## Kontext

Start: Go-Server im Dev-Mode (`K3C_DEV=1`, über k3c-dev `svc_start` bzw. `task start`), Asset-Studio unter `/studio/` auf demselben Rechner (Loopback), Claude Code CLI auf dem Rechner von 🧑 angemeldet. **Umgebung live:** Claude bereitet vor und trägt das Urteil von 🧑 ein, urteilt aber nicht selbst und schickt keine Chat-Nachricht. Browser-Prüfungen durch Claude nur mit Freigabe von 🧑 für diesen Lauf.

Punkte: (1) Chat rechts auf allen Seiten ein- und ausblendbar; (2) „Prompt-Grundgerüst“ füllt das Eingabefeld, 🧑 ergänzt Wünsche (z. B. „Vier Inseln, die dritte ist ein reines Höhlenabenteuer“) und sendet, die Antwort kommt fortlaufend, Abbruch funktioniert; (3) die Antwort wird als Entwurf geladen, Fehler stehen am Entwurf, nichts wird gespeichert, bis 🧑 speichert; (4) die Welt hat mindestens zwei Inseln und startet über „Im Spiel öffnen“; (5) `.chats/` enthält den Verlauf, `git status` zeigt ihn nicht. Hardware entkoppelt: WZ19.5 ist keine Abhängigkeit des Reviews.

## Kontext

Leitfaden `docs/standards/rust-werkzeuge.md`; Entscheidung für RU71 (Claude, Planung 2026-11-26): **Das Repo wird Rust + TypeScript. Go-CLIs, die nur Prozesse, Git und Dateien orchestrieren, werden TypeScript unter bun** (wie `tools/paper`, `tools/rigexport`): kein Bauschritt vor `check:diff`, Tests im Vitest der Wurzel, Lint/Typecheck der Wurzel. Beschreibung: `tools/checkdiff/codemap.md`. Tests: `select_test.go` (Tabelle), `simlist_test.go`.

## Schritte

1. `git merge origin/main`. Orakel festhalten, bevor etwas umgestellt wird: `mkdir -p .work/orakel`; `task check:diff:plan > .work/orakel/plan-head.txt`; `CHECK_BASE=origin/main task check:diff:plan > .work/orakel/plan-main.txt`; `task ops:aufraeumen -- --dry > .work/orakel/cleanup-dry.txt`.
2. `tools/checkdiff` nach TypeScript: `main.ts` (Flags, Exit-Code), `select.ts` (aus `select.go` und `rust.go`, ohne Go-Module), `repo.ts` (nur Git), `steps.ts` (Bahnen `js` und `rust`), `run.ts` (Stufen, Parallelität, Zeitmarker). Tests: `select.test.ts` portiert jede Zeile aus `select_test.go`, die keine Go-Datei betrifft; Zeilen nur für Go entfallen (Anzahl im Ergebnis nennen). Dazu ein Test für das Format der Zeitmarker.
3. `tools/cleanup` nach TypeScript: `main.ts`, `cleanup.ts`, `bin.ts`; Tests `cleanup.test.ts`, `bin.test.ts` aus den Go-Tests; Liste alter EXE erweitern (Kontext).
4. `tsconfig.json` erweitern; `Taskfile.yml`: `check:diff`, `check:diff:plan`, `check:diff:js`, `check:diff:rust` rufen `bun tools/checkdiff/main.ts …` mit denselben Argumenten; `check:diff:go` entfällt; Beschreibungen ohne `go vet`. `check:go` bleibt unverändert. `scripts/Taskfile.yml` › `aufraeumen`: `bun tools/cleanup/main.ts {{.CLI_ARGS}}`, Vorbedingung Go entfällt.
5. Orakel-Vergleich: dieselben drei Befehle wie in Schritt 1 erneut nach `.work/orakel/*-ts.txt`; `diff` gegen die Go-Ausgaben. Erlaubte Unterschiede nur: fehlende Schritte der Bahn `go` und die drei neuen EXE-Namen. Jeder andere Unterschied wird behoben.
6. `tools/checkdiff/codemap.md` und `tools/cleanup/codemap.md` auf die TS-Fassung umschreiben (Hinweis: Go-Dateien nur noch für `-gopkgs`/`-wbpkgs`, Löschung in RU71.4).
7. Gezielt: `bunx vitest run tools/checkdiff tools/cleanup`, `task lint`, `task typecheck`. Dann `task check:diff` (die neue Fassung prüft sich selbst) über `check_run`. `.work/orakel/` löschen.
8. Ergebnis (Orakel-Vergleich mit Zahl der portierten und entfallenen Tests) eintragen, Status `fertig`, ein Commit, Push.

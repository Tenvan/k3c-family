## Kontext

- Vorlage (nur lesen): `src/core/rng.ts`. `hashSeed`: FNV-1a über UTF-16-Codeeinheiten (`charCodeAt`) → in Go
  `utf16.Encode([]rune(seed))`; `Math.imul` und `>>> 0` → `uint32`-Arithmetik; `next()` = `uint32 / 4294967296`.
  `int(min, max) = min + floor(next() * (max - min + 1))`.
- `weighted` iteriert in Einfügereihenfolge (`Object.entries`) → Go nimmt eine geordnete Liste statt einer `map`.
  `pick` geht in Go als Funktion (Methoden können nicht generisch sein) oder über `Int(0, len-1)`.
- Golden-Datei: `testdata/golden/rng.json` aus SP04.1. Go-Tests lesen sie relativ zum Paket (`../../testdata/golden/`).
- Go darf `x*y + z` fusionieren (FMA): Produkte vor einer Addition mit `float64(…)` runden.
- Nur Standardbibliothek. Schichtgrenzen: `engine/rng` importiert nichts aus `engine/room`, `engine/net`, `cmd/`.
